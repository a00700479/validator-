# Скрипт для проверки белых списков

## 📋 Что делает эта программа?

**Валидация файлов** - проверяет CSV файлы на ошибки:
- ✅ Проверяет правильность заголовков и обязательных полей
- ✅ Проверяет формат ОГРН, IP-адресов, портов, масок подсетей
- ✅ Проверяет, что IP-адреса не находятся в запрещенных подсетях (blacklist)
  - ⚠️ Исключение: адреса с маской /32 (IPv4) или /128 (IPv6) в blacklist - допустимы
- ✅ Проверяет страну регистрации IP-адреса (должна быть РФ)
- ✅ Находит дубликаты записей
- ✅ Создает два отчета: полный и только с ошибками

**Поиск IP-адресов** - ищет указанные IP-адреса в CSV файлах с учетом подсетей.

### Шаг 4.5: Установка whois (опционально, для проверки страны IP)

**Что такое whois?**
Утилита whois нужна для проверки страны регистрации IP-адреса. Если вы планируете использовать флаг `--skip-whois`, этот шаг можно пропустить.

**Способ 1: Sysinternals Suite (рекомендуется)**

1. **Скачайте whois от Microsoft:**
   - Перейдите на страницу: https://learn.microsoft.com/en-us/sysinternals/downloads/whois
   - Нажмите "Download Whois"
   - Скачается архив whois.zip

2. **Распакуйте и установите:**
   - Распакуйте whois.zip
   - Скопируйте файл `whois.exe` или `whois64.exe` в папку `C:\Windows\System32\`
   - Для этого понадобятся права администратора

3. **Проверьте установку:**
   - Откройте новую командную строку
   - Введите: `whois`
   - Должна появиться информация об использовании команды

**Способ 2: Через Chocolatey (если установлен)**

Если у вас установлен пакетный менеджер Chocolatey:

```cmd
choco install sysinternals
```

**Способ 3: Portable (без установки)**

Можно положить `whois.exe` в папку с программой validator и он будет работать.

**Примечание:** Без whois можно работать с флагом `--skip-whois` - проверка страны будет пропущена.

### Шаг 5: Запуск проверки файла

**Важно:** Если вы используете виртуальное окружение, убедитесь что оно активировано перед запуском программы!

#### Вариант 1: Быстрая проверка одного файла (рекомендуется для начала)

Скопируйте эту команду, замените `filename.csv` на имя вашего файла и выполните:

```cmd
python main.py validate --input filename.csv --output result.csv --skip-whois
```

**Что означает команда:**
- `python main.py validate` - запуск программы в режиме проверки
- `--input data.csv` - проверяем файл data.csv (ЗАМЕНИТЕ на имя вашего файла!)
- `--output result.csv` - результаты сохранить как result.csv (можете изменить имя)
- `--skip-whois` - пропустить проверку страны по IP (работает быстрее)

**Результат:**
Программа создаст два файла:
- `result_full.csv` - ВСЕ строки из вашего файла с добавленной колонкой "результат проверки"
- `result_errors.csv` - ТОЛЬКО строки с ошибками

#### Вариант 2: Проверка нескольких файлов сразу

Если нужно проверить несколько файлов и объединить их:

```cmd
python main.py validate --input "file1.csv,file2.csv,file3.csv" --output result.csv --skip-whois
```

### Шаг 6: Просмотр результатов

1. **Откройте файл `result_errors.csv`** в Excel или текстовом редакторе
2. **Колонка "результат проверки"** содержит описание всех найденных ошибок:
   - `ok` - строка без ошибок
   - `[НАЗВАНИЕ_ОШИБКИ] описание; ...` - найденные ошибки
3. **Колонка "source_file"** показывает из какого файла эта строка (при проверке нескольких файлов)

**Совет:** Если вы установили whois, можете запустить проверку без флага `--skip-whois` для проверки страны регистрации IP:

```cmd
python main.py validate --input filename.csv --output result.csv
```

## 🔍 Режим поиска IP-адресов

Помимо валидации, программа умеет искать IP-адреса в файлах с учетом подсетей.

### Поиск одного адреса

**Windows:**
```cmd
python main.py search --address 192.168.1.1 --files data.csv
```

**Unix:**
```bash
python main.py search --address 192.168.1.1 --files data.csv
```

*(Если виртуальное окружение НЕ активировано, используйте `python3` вместо `python`)*

### Поиск нескольких адресов

**Windows:**
```cmd
python main.py search --address 192.168.1.1,10.0.0.5,8.8.8.8 --files data.csv
```

**Unix:**
```bash
python main.py search --address 192.168.1.1,10.0.0.5,8.8.8.8 --files data.csv
```

### Поиск адресов из файла

1. Создайте текстовый файл `addresses.txt`, каждый адрес на новой строке:
   ```
   192.168.1.1
   10.0.0.5
   8.8.8.8
   ```

2. Запустите поиск:

**Windows:**
```cmd
python main.py search --address addresses.txt --files data.csv
```

**Unix:**
```bash
python main.py search --address addresses.txt --files data.csv
```

### Поиск в нескольких файлах

**Windows:**
```cmd
python main.py search --address 192.168.1.1 --files file1.csv file2.csv file3.csv
```

**Unix:**
```bash
python main.py search --address 192.168.1.1 --files *.csv
```

## 📝 Формат входного файла

Программа ожидает CSV файл с разделителем `|` (вертикальная черта) и следующими колонками:

| № | Название колонки | Обязательная | Описание |
|---|------------------|--------------|----------|
| 1 | Number | ✅ | Уникальный номер записи |
| 2 | Название сервиса | ❌ | Название сервиса |
| 3 | юр_лицо | ❌ | Юридическое лицо |
| 4 | ОГРН | ✅ | ОГРН (13 цифр) |
| 5 | IPv4/IPv6 | ✅ | Версия IP (v4 или v6) |
| 6 | Сеть в формате network ID | ✅ | IP-адрес сети (без маски) |
| 7 | MASK | ✅ | Маска подсети (например: /24) |
| 8 | Port | ✅ | Порт (число, диапазон или список) |
| 9 | CDN Yes/No | ✅ | Использование CDN (yes или no) |
| 10 | Protocol | ✅ | Протокол (tcp, udp, esp) |
| 11 | DNS Host | ❌ | DNS хост |
| 12 | SNI/HTTP HOST | ❌ | SNI/HTTP хост |
| 13 | Проверочный IP+Порт | ✅ | IP:порт для проверки |
| 14 | URL проверки | ❌ | URL для проверки |
| 15 | Способ проверки | ✅ | Метод проверки (ping, curl, telnet, dig) |
| 16 | Описание | ❌ | Описание |

**Пример правильной строки:**
```
1|Мой сервис|ООО "Компания"|1234567890123|v4|192.168.1.0|/24|443|no|tcp|example.com|example.com|192.168.1.1:443|https://example.com|ping,curl|Тестовый сервис
```

## 🔧 Типы проверок

Программа выполняет следующие проверки:

1. **REQUIRED** - Проверка заполнения обязательных полей
2. **UNIQUE** - Проверка уникальности номеров (Number)
3. **OGRN** - Формат ОГРН (строго 13 цифр)
4. **IP_VERSION** - Версия IP (v4 или v6)
5. **NETWORK** - Формат сетевого адреса (валидный IP)
6. **MASK** - Формат маски (/XX, правильный диапазон)
7. **HOST_BITS** - Проверка host bits (сеть должна быть каноничной)
8. **PORT** - Формат порта (1-65535, диапазоны, списки)
9. **CDN** - Значение CDN (yes/no)
10. **PROTOCOL** - Протокол (tcp, udp, esp или комбинации)
11. **CHECK_IP_PORT** - Формат проверочного IP+Порт
12. **METHOD** - Способ проверки (ping, telnet, curl, dig)
13. **BLACKLIST** - Проверка blacklist подсетей
    - **Исключение:** Если в blacklist указан адрес с маской /32 (IPv4) или /128 (IPv6), такое совпадение допустимо
14. **WHOIS** - Проверка страны по IP (только если не указан --skip-whois)

## ❓ Часто задаваемые вопросы

### Программа не запускается, пишет "python не является внутренней или внешней командой"

**Решение для Windows:**
1. Python не установлен или не добавлен в PATH
2. Переустановите Python и ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH"
3. После установки перезапустите командную строку

### Ошибка "No module named 'pandas'"

**Решение:**
Установите библиотеки:
```cmd
pip install pandas tqdm
```

### Ошибка "Файл не найден"

**Решение:**
1. Убедитесь, что вы находитесь в правильной папке (команда `cd`)
2. Проверьте правильность имени файла (с учетом расширения .csv)
3. Используйте полный путь к файлу, например:
   ```cmd
   python main.py validate --input C:\Users\Username\Documents\data.csv --output C:\Users\Username\Documents\result.csv --skip-whois
   ```

### Программа работает очень долго

**Решение:**
1. Используйте флаг `--skip-whois` - это сильно ускорит проверку
2. Проверка страны через whois делается для каждого уникального IP и может занимать время

### Как обновить blacklist?

**Решение:**
Отредактируйте файл `config\blacklist.json` (Windows) или `config/blacklist.json` (Unix).

Формат:
```json
{
  "источник_1": [
    "192.168.0.0/16",
    "10.0.0.0/8"
  ],
  "источник_2": [
    "172.16.0.0/12"
  ]
}
```

**Примечание:** Адреса с маской /32 (IPv4) или /128 (IPv6) в blacklist считаются исключениями и не вызывают ошибку при совпадении.
